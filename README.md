# 📘 01_Basics_js 
# 🚀 JavaScript fundamentals
* Welcome to my JavaScript learning repository! This repo contains simple examples and covering the core concepts of JavaScript. 
* Each file focuses on a specific topic and covering fundamental concepts such as variables, data types, type conversion, operators, strings, numbers, and dates.

## 🛠️ Prerequisites

Before running the examples, make sure you have:

* Basic understanding of programming concepts
* Node.js installed (optional)
* Check Node.js installation:

```bash
node -v
```
